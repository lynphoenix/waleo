设备管理 API

函数

get_training_device

def get_training_device() -> torch.device

获取训练设备（仅 CUDA）。

返回：torch.device - CUDA 设备

异常： - RuntimeError - 如果 CUDA 不可用

示例：

device = get_training_device()  # cuda:0
model.to(device)

get_inference_device

def get_inference_device() -> torch.device

获取推理设备（CUDA > MPS > CPU）。

返回：torch.device - 可用设备

示例：

device = get_inference_device()  # 自动选择最佳设备
model.to(device)

get_device

def get_device(device_str: str) -> torch.device

根据字符串获取设备。

参数： - device_str (str) - 设备字符串（"cuda", "cuda:0", "mps", "cpu"）

返回：torch.device

示例：

device = get_device("cuda:0")
device = get_device("cpu")

setup_distributed

def setup_distributed(backend: str = "nccl") -> None

初始化分布式训练环境。

参数： - backend (str) - 后端类型（默认："nccl"）

环境变量： - RANK - 进程 rank - WORLD_SIZE - 总进程数 - LOCAL_RANK - 本地 rank - MASTER_ADDR - 主节点地址 - MASTER_PORT - 主节点端口
