launch_multi_process

def launch_multi_process(
    num_gpus: int,
    func: Callable,
    args: Tuple = (),
) -> None

启动多进程训练（单节点）。

参数： - num_gpus - GPU 数量 - func - 训练函数，签名为 func(rank, world_size, *args) - args - 传递给函数的额外参数

示例：

def train(rank, world_size):
    # 训练代码
    pass

launch_multi_process(num_gpus=4, func=train)

all_reduce

def all_reduce(
    tensor: torch.Tensor,
    op: str = "avg"
) -> torch.Tensor

All-Reduce 张量跨进程。

参数： - tensor - 要聚合的张量 - op - 操作类型："avg", "sum", "max", "min"

返回：聚合后的张量
