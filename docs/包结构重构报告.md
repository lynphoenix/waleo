# Waleo 包结构重构报告

## 执行日期
2026-01-25

## 重构目标

将原来分散的三个独立包（waleo-utils, waleo-config, waleo-sim）统一为单一的 `waleo` 包，使用现代化的 src-layout 结构。

---

## 变更概览

### 旧结构
```
waleo/
├── waleo-utils/
│   ├── waleo_utils/
│   ├── tests/
│   ├── pyproject.toml
│   └── README.md
├── waleo-config/
│   ├── waleo_config/
│   ├── tests/
│   ├── pyproject.toml
│   └── README.md
└── waleo-sim/
    ├── waleo_sim/
    ├── examples/
    ├── tests/
    ├── pyproject.toml
    └── README.md
```

**问题**:
- 三个独立的包需要分别安装
- 依赖关系管理复杂
- 导入路径不统一（waleo_utils, waleo_config, waleo_sim）
- 维护三份 pyproject.toml

### 新结构
```
waleo/
├── src/waleo/              # 统一的源代码目录
│   ├── __init__.py         # 主包入口
│   ├── utils/              # 基础设施工具
│   ├── config/             # 配置管理
│   └── sim/                # 仿真环境
├── tests/                  # 统一的测试目录
│   ├── test_utils/
│   ├── test_config/
│   └── test_sim/
├── examples/               # 统一的示例目录
│   └── maniskill/
├── assets/                 # 资源文件
├── docs/                   # 文档
├── pyproject.toml          # 单一配置文件
└── README.md               # 主文档
```

**优势**:
- ✅ 单一包安装：`pip install -e .`
- ✅ 统一导入路径：`from waleo.utils import ...`
- ✅ 简化依赖管理：一个 pyproject.toml
- ✅ 符合现代 Python 包规范（src-layout）
- ✅ 更清晰的项目结构

---

## 详细变更

### 1. 目录结构迁移

#### 源代码迁移
```bash
waleo-utils/waleo_utils/  →  src/waleo/utils/
waleo-config/waleo_config/ →  src/waleo/config/
waleo-sim/waleo_sim/       →  src/waleo/sim/
```

#### 测试迁移
```bash
waleo-utils/tests/  →  tests/test_utils/
waleo-config/tests/ →  tests/test_config/
waleo-sim/tests/    →  tests/test_sim/
```

#### 示例迁移
```bash
waleo-sim/examples/  →  examples/
```

### 2. 导入路径更新

所有模块内部导入从旧包名更新为新包名：

| 旧导入路径 | 新导入路径 |
|-----------|-----------|
| `from waleo_utils import ...` | `from waleo.utils import ...` |
| `from waleo_utils.xxx import ...` | `from waleo.utils.xxx import ...` |
| `from waleo_config import ...` | `from waleo.config import ...` |
| `from waleo_config.xxx import ...` | `from waleo.config.xxx import ...` |
| `from waleo_sim import ...` | `from waleo.sim import ...` |
| `from waleo_sim.xxx import ...` | `from waleo.sim.xxx import ...` |

**更新范围**:
- ✅ 所有源代码文件（src/waleo/**/*.py）
- ✅ 所有测试文件（tests/**/*.py）
- ✅ 所有示例文件（examples/**/*.py）

**更新方法**: 使用 sed 批量替换
```bash
find src/waleo/utils -name "*.py" -exec sed -i 's/from waleo_utils\./from waleo.utils./g' {} \;
find src/waleo/config -name "*.py" -exec sed -i 's/from waleo_config\./from waleo.config./g' {} \;
find src/waleo/sim -name "*.py" -exec sed -i 's/from waleo_sim\./from waleo.sim./g' {} \;

# 测试和示例同样处理
find tests -name "*.py" -exec sed -i 's/from waleo_utils/from waleo.utils/g' {} \;
find examples -name "*.py" -exec sed -i 's/from waleo_sim/from waleo.sim/g' {} \;
```

### 3. 包配置统一

创建统一的 `pyproject.toml`:

```toml
[project]
name = "waleo"
version = "0.1.0"
description = "Waleo - Complete Robotics Learning Framework..."

dependencies = [
    "torch>=2.0.0",
    "numpy>=1.24.0",
    "tensorboard>=2.10.0",
    "pillow>=9.0.0",
]

[project.optional-dependencies]
mujoco = ["mujoco>=3.0.0"]
pybullet = ["pybullet>=3.2.0"]
maniskill = ["mani-skill>=3.0.0"]
video = ["imageio>=2.20.0", "imageio-ffmpeg>=0.4.7"]
# ... 其他可选依赖

[tool.setuptools.packages.find]
where = ["src"]

[tool.setuptools.package-dir]
"" = "src"
```

### 4. 包入口创建

创建 `src/waleo/__init__.py`:

```python
"""Waleo - Robotics Learning Framework"""

__version__ = "0.1.0"

from . import utils
from . import config
from . import sim

__all__ = ["utils", "config", "sim", "__version__"]
```

这样用户可以选择两种导入方式：

```python
# 方式1: 直接导入子模块
from waleo import utils
device = utils.get_training_device()

# 方式2: 完整路径导入
from waleo.utils import get_training_device
device = get_training_device()
```

### 5. 安装和测试

#### 安装

