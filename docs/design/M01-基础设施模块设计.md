## 1. 模块概述

**模块名称**: `waleo.utils`
**版本**: v0.1.0
**描述**: 提供机器人学习框架所需的基础工具函数和常量定义，是所有其他模块的依赖基础。

---

## 2. 模块职责

### 2.1 核心职责
- **设备分层管理**：训练设备（CUDA+NCCL） vs 推理设备（CUDA/MPS/CPU）
- **分布式训练支持**：NCCL 单机多卡/多机多卡通信、进程组初始化
- **通信基础设施**：RPC 通信框架、序列化工具、客户端/服务端基类
- **日志记录**：TensorBoard日志、格式化输出、文件日志、分布式日志、指标追踪
- **随机数管理**：种子设置、状态保存/恢复、分布式随机数同步
- **时间测量**：性能计时器、同步点测量、代码性能分析
- **文件 I/O**：视频/图像保存加载、JSON 序列化
- **常量定义**：路径、键名、环境变量

### 2.2 非职责
- 不涉及任何深度学习模型逻辑
- 不涉及机器人硬件控制细节
- 不涉及数据处理（属于 M03 数据集模块）
- 不涉及分布式训练的具体训练循环（属于 M13 训练模块）
- 不涉及具体的通信协议实现（属于 M21 通信服务模块）

## 5. 与设计文档的变化

### 5.1 API命名变化

| 原设计 | 实际实现 | 说明 |
|--------|---------|------|
| `init_logging()` | `create_logger()` | 更直观的命名 |
| `get_logger()` | 合并到`create_logger()` | 简化API |
| `MetricsTracker` | `MetricTracker` | 拼写简化 |
| `write_video()` | `save_video()` | 与load_video对称 |
| `deserialize_json_into_object()` | `load_json()` | 更简洁 |
| `get_rng_state()` 等函数式API | `RNGManager` 类 | 更现代的面向对象设计 |

### 5.2 新增功能

**日志增强**:
- `TBLogger` - TensorBoard集成
- `ProgressMeter` - 进度显示

**随机数增强**:
- `RNGManager` - 统一管理类
- `ForkedRNG` - 多进程安全的RNG
- `get_seed()` - 获取当前种子
- `seed_worker()` - DataLoader worker初始化

**时间测量增强**:
- `CodeTimer` - 代码块计时器
- `time_function` - 函数计时
- `timer` - 灵活的装饰器/上下文

**I/O增强**:
- `load_video()` - 视频加载
- `save_image()`, `load_image()` - 图像I/O
- `save_json_custom()` - 自定义序列化
- `update_json()` - JSON更新
- `get_json_value()` - JSON读取

### 5.3 设计改进理由

1. **命名一致性**: `save_*/load_*` 配对更直观
2. **面向对象**: `RNGManager` 比函数式接口更易管理状态
3. **功能完整**: 补充了设计中未考虑的实用功能
4. **实战导向**: 基于实际训练需求添加TensorBoard、进度条等

## 8. 使用建议

### 8.1 推荐实践

```python
# 设备管理
device = get_training_device()  # 训练时
device = get_inference_device()  # 推理时

# 随机数（使用管理器）
rng = RNGManager(seed=42)
# ... training ...
rng.save_state("checkpoint/rng.pkl")

# 日志（使用TensorBoard）
logger = TBLogger("runs/experiment")
logger.log_scalar("loss", 0.5, step=100)

# 计时（使用装饰器）
@timer("forward_pass")
def forward(model, x):
    return model(x)
```

### 8.2 性能优化

- 使用 `CodeTimer` 识别性能瓶颈
- 使用 `RNGManager` 管理复现性
- 使用 `TBLogger` 记录训练过程
