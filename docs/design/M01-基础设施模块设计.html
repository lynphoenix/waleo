M01: 基础设施模块 (waleo-utils) 设计文档

优先级: P0 (核心基础) 依赖: 无 状态: 设计中

1. 模块概述

模块名称: waleo-utils 版本: v0.1.0 描述: 提供机器人学习框架所需的基础工具函数和常量定义，是所有其他模块的依赖基础。

2. 模块职责

2.1 核心职责

  • 设备分层管理：训练设备（CUDA+NCCL） vs 推理设备（CUDA/MPS/CPU）
  • 分布式训练支持：NCCL 单机多卡/多机多卡通信、进程组初始化
  • 通信基础设施：RPC 通信框架、序列化工具、客户端/服务端基类
  • 日志记录：格式化输出、文件日志、分布式日志
  • 随机数管理：种子设置、状态保存/恢复、分布式随机数同步
  • 时间测量：性能计时器、同步点测量
  • 文件 I/O：视频保存、JSON 序列化
  • 常量定义：路径、键名、环境变量

2.2 非职责

  • 不涉及任何深度学习模型逻辑
  • 不涉及机器人硬件控制细节
  • 不涉及数据处理（属于 M03 数据集模块）
  • 不涉及分布式训练的具体训练循环（属于 M13 训练模块）
  • 不涉及具体的通信协议实现（属于 M21 通信服务模块）

4. API 设计

4.1 设备管理 (device/)

4.1.1 基础设备管理 (manager.py)

设计理念：根据使用场景分层选择设备

函数名 输入 输出 描述
get_training_device() 无 torch.device 获取训练设备（仅 CUDA）
get_inference_device() 无 torch.device 获取推理设备（CUDA > MPS > CPU）
get_device(device_str) str torch.device 根据字符串获取设备
is_device_available(device_str) str bool 检查设备是否可用
get_device_count(device_type) str int 获取指定类型的设备数量
get_device_capabilities() 无 dict 获取设备能力信息

使用示例

from waleo_utils.device import get_training_device, get_inference_device, get_device_capabilities

# 训练：只使用 CUDA
train_device = get_training_device()  # cuda:0 或抛出异常

# 推理：可以使用任何设备
infer_device = get_inference_device()  # cuda/mps/cpu

# 获取设备能力
caps = get_device_capabilities()
# {
#     'cuda': {'available': True, 'count': 4, 'nccl': True},
#     'mps': {'available': True, 'count': 1, 'nccl': False},
#     'cpu': {'available': True}
# }

4.1.2 分布式设备 (distributed.py)

设计理念：支持单机多卡和多机多卡，使用统一接口

函数名 输入 输出 描述
setup_distributed(backend="nccl") str 无 初始化分布式环境
setup_distributed_multinode(init_method, world_size, rank) str, int, int 无 初始化多机分布式
get_world_size() 无 int 获取进程总数
get_rank() 无 int 获取当前进程 rank
get_local_rank() 无 int 获取本地进程 rank
is_main_process() 无 bool 是否为主进程
barrier() 无 无 同步所有进程
destroy_distributed() 无 无 清理分布式环境

使用示例

from waleo_utils.device import setup_distributed, get_rank, get_world_size

# 单机多卡（自动检测）
setup_distributed(backend="nccl")

# 多机多卡（手动指定）
# Node 0:
setup_distributed_multinode(
    init_method="tcp://192.168.1.1:12345",
    world_size=8,  # 2 nodes × 4 GPUs
    rank=0
)

# Node 1:
setup_distributed_multinode(
    init_method="tcp://192.168.1.1:12345",
    world_size=8,
    rank=4  # offset by node 0's GPUs
)

rank = get_rank()
world_size = get_world_size()
device = torch.device(f"cuda:{get_local_rank()}")

依赖

  • torch
  • torch.distributed
  • 无其他 waleo 模块依赖

from waleo_utils.distributed import launch_multi_process, launch_multinode

def train_worker(rank, world_size, config):
    """每个进程的训练函数"""
    setup_distributed()
    device = torch.device(f"cuda:{rank}")
    model = MyModel().to(device)
    model = torch.nn.parallel.DistributedDataParallel(
        model, device_ids=[rank]
    )
    # 训练...

# 单机多卡
launch_multi_process(num_gpus=4, func=train_worker, args=(config,))

# 多机多卡
nodes_config = [
    {"host": "node0", "num_gpus": 4},
    {"host": "node1", "num_gpus": 4},
]
launch_multinode(nodes_config, func=train_worker, args=(config,))

4.3.5 协议定义 (protocol.py)

from enum import Enum

class MessageType(Enum):
    """消息类型"""
    REQUEST = "request"
    RESPONSE = "response"
    STREAM_START = "stream_start"
    STREAM_CHUNK = "stream_chunk"
    STREAM_END = "stream_end"
    ERROR = "error"

class ErrorCode(Enum):
    """错误码"""
    OK = 0
    NOT_FOUND = 1
    INVALID_REQUEST = 2
    INTERNAL_ERROR = 3
    TIMEOUT = 4

@dataclass
class RPCMessage:
    """RPC 消息格式"""
    msg_type: MessageType
    msg_id: str
    method: str | None = None
    args: tuple | None = None
    kwargs: dict | None = None
    result: Any | None = None
    error: ErrorCode | None = None
    error_msg: str | None = None

使用示例

from waleo_utils.communication import RPCClient, RPCServer, serialize, deserialize

# 服务端
class MyService(RPCServer):
    def __init__(self):
        super().__init__(host="0.0.0.0", port=5000)
        self.register_method("predict", self.predict)
        self.register_method("process_stream", self.process_stream)

    def predict(self, inputs: dict) -> dict:
        """推理方法"""
        # 处理输入并返回结果
        return {"action": [0.1, 0.2, 0.3]}

    def process_stream(self, inputs: dict):
        """流式处理"""
        for i in range(10):
            yield {"step": i, "value": i * 0.1}

# 启动服务
service = MyService()
service.start()

# 客户端
client = RPCClient(host="localhost", port=5000)
client.connect()

# 同步调用
result = client.call("predict", inputs={"obs": [...]})
print(result)  # {"action": [0.1, 0.2, 0.3]}

# 异步调用
result = await client.call_async("predict", inputs={"obs": [...]})

# 流式调用
for chunk in client.call_stream("process_stream", inputs={"data": [...]}):
    print(chunk)  # {"step": 0, "value": 0.0}, {"step": 1, "value": 0.1}, ...

│  │  └────────────┬─────────────────────────────────┘  │    │
│  │               │                                      │    │

│  └────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘

关键点： - 机器人本体只需要 MPS/CPU（低算力） - 训练和推理在 CUDA 服务器完成 - 通过 RPC 通信异步请求推理 - 机器人本体只负责：采集 → 请求 → 执行

12. 实现优先级

Phase 1: 核心功能（必须）- 基础设施

  1. device/manager.py - 设备管理（训练/推理分离）
  2. device/distributed.py - 分布式设备（NCCL 多机多卡）
  3. constants.py - 常量定义
  4. timing/timer.py - 时间测量

Phase 2: 分布式训练（必须）- CUDA 多卡/多机训练

  1. distributed/launcher.py - 多进程/多机启动
  2. distributed/reducer.py - 梯度同步
  3. distributed/state.py - 分布式状态管理
  4. random/state.py - RNG 管理（含分布式同步）

Phase 3: 通信基础设施（必须）- 远程推理基础

  1. communication/base.py - RPC 基类
  2. communication/client.py - 客户端基类
  3. communication/server.py - 服务端基类
  4. communication/serialization.py - 序列化工具
  5. communication/protocol.py - 协议定义

Phase 4: 辅助功能（推荐）

  1. logging/metrics.py - 指标追踪
  2. logging/formatter.py - 日志格式化
  3. io/json.py - JSON 序列化
  4. io/video.py - 视频保存
