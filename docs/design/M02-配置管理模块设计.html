M02: 配置管理模块 (waleo-config) 设计文档

优先级: P0 (核心基础) 依赖: M01 (waleo-utils) 状态: 设计中

1. 模块概述

模块名称: waleo-config 版本: v0.1.0 描述: 提供统一的配置管理系统，支持数据类定义、命令行解析、类型验证和插件加载。

2. 模块职责

2.1 核心职责

  • 配置数据类定义（Dataset, Eval, Training 等配置）
  • 类型系统定义（FeatureType, NormalizationMode）
  • 命令行参数解析
  • 配置验证和默认值管理
  • 配置文件加载（YAML/JSON）
  • 插件系统支持

2.2 非职责

  • 不涉及具体配置值的业务逻辑
  • 不涉及配置存储（由调用方决定）
  • 不涉及深度学习模型配置（属于 M04 策略模块）

4.2 数据集配置 (dataset/config.py)

数据类定义

@dataclass
class ImageTransformsConfig:
    """图像变换配置"""
    enable: bool = True
    random_resize: bool = False
    random_crop: bool = False
    horizontal_flip: bool = False
    vertical_flip: bool = False

@dataclass
class DatasetConfig:
    """数据集配置"""
    # 必需参数
    repo_id: str

    # 可选参数
    root: str | None = None           # 数据集存储根目录
    episodes: list[int] | None = None # 指定使用的 episode
    image_transforms: ImageTransformsConfig = field(default_factory=ImageTransformsConfig)
    revision: str | None = None       # Hub 版本
    use_imagenet_stats: bool = True   # 使用 ImageNet 统计信息
    video_backend: str = "pyav"       # 视频后端: "pyav" 或 "video_codec"

    def __post_init__(self):
        """配置验证"""
        if self.video_backend not in ["pyav", "video_codec"]:
            raise ValueError(f"Invalid video_backend: {self.video_backend}")

配置示例

# dataset_config.yaml
repo_id: "waleo/pusht"
root: "data/datasets"
episodes: [1, 2, 3, 4, 5]
image_transforms:
  enable: true
  random_crop: true
use_imagenet_stats: true
video_backend: "pyav"

使用示例

from lerobot_config.dataset import DatasetConfig

# 方式1: 直接创建
config = DatasetConfig(
    repo_id="waleo/pusht",
    episodes=[1, 2, 3, 4, 5],
    use_imagenet_stats=False
)

# 方式2: 从文件加载
config = DatasetConfig.from_yaml("dataset_config.yaml")

# 方式3: 命令行覆盖
# python train.py --dataset.repo_id=waleo/aloha --dataset.episodes=[1,2,3]

4.3 训练配置 (training/config.py)

数据类定义

@dataclass
class OptimizerConfig:
    """优化器配置"""
    type: str = "adam"          # adam, adamw, sgd
    lr: float = 1e-4
    betas: tuple[float, float] = (0.9, 0.999)
    eps: float = 1e-8
    weight_decay: float = 0.0

@dataclass
class SchedulerConfig:
    """学习率调度器配置"""
    type: str = "cosine"        # cosine, step, constant
    num_warmup_steps: int = 500
    min_lr_ratio: float = 0.0

@dataclass
class CheckpointConfig:
    """检查点配置"""
    save_every: int = 5000      # 每 N 步保存
    save_total_limit: int = 3   # 最多保留 N 个检查点
    save_optimizer: bool = True

@dataclass
class TrainingConfig:
    """训练配置"""
    # 数据集相关
    offline_steps: int = 50000
    online_steps: int = 0
    rollout_n_episodes: int = 50
    rollout_batch_size: int = 8

    # 训练超参数
    batch_size: int = 64
    num_workers: int = 4
    seed: int = 1337

    # 设备和日志
    device: str = "cuda"        # cuda, mps, cpu
    log_freq: int = 100
    eval_freq: int = 5000

    # 子配置
    optimizer: OptimizerConfig = field(default_factory=OptimizerConfig)
    scheduler: SchedulerConfig = field(default_factory=SchedulerConfig)
    checkpoint: CheckpointConfig = field(default_factory=CheckpointConfig)

    def __post_init__(self):
        """配置验证"""
        if self.offline_steps <= 0:
            raise ValueError("offline_steps must be positive")
        if self.batch_size <= 0:
            raise ValueError("batch_size must be positive")

配置示例

# training_config.yaml
offline_steps: 100000
batch_size: 32
num_workers: 8
device: "cuda"
optimizer:
  type: "adamw"
  lr: 0.0001
  weight_decay: 0.0001
scheduler:
  type: "cosine"
  num_warmup_steps: 1000
checkpoint:
  save_every: 10000
  save_total_limit: 5

使用示例

from lerobot_config.training import TrainingConfig

config = TrainingConfig(
    offline_steps=100000,
    batch_size=32,
    optimizer=OptimizerConfig(type="adamw", lr=1e-4, weight_decay=1e-4)
)

# 访问嵌套配置
lr = config.optimizer.lr

依赖

  • dataclasses (标准库)
  • lerobot-utils.device (M01，用于设备验证)

4.4 评估配置 (eval/config.py)

数据类定义

@dataclass
class EvalConfig:
    """评估配置"""
    n_episodes: int = 50
    batch_size: int = 50          # 并行环境数量
    use_async_envs: bool = False  # 使用异步环境（多进程）
    save_video: bool = True       # 保存评估视频
    video_fps: int = 30

    def __post_init__(self):
        """配置验证"""
        if self.batch_size > self.n_episodes:
            import warnings
            warnings.warn(
                f"Eval batch size ({self.batch_size}) > n_episodes ({self.n_episodes}). "
                "Some environments will be unused."
            )

使用示例

from lerobot_config.eval import EvalConfig

config = EvalConfig(
    n_episodes=100,
    batch_size=10,
    save_video=True
)

  • dataclasses (标准库)

4.5 命令行解析 (parser/cli.py)

函数列表

函数名 输入 输出 描述
parse_config(config_cls, args=None) type, List[str] config_cls 解析命令行并创建配置对象
parse_arg(arg_name, args=None) str, List[str] str | None 解析单个参数
get_cli_overrides(field_name, args=None) str, List[str] List[str] 获取字段的所有覆盖参数
filter_args(fields_to_filter, args=None) str | List[str], List[str] List[str] 过滤掉指定字段的参数

使用示例

from lerobot_config.parser import parse_config
from lerobot_config.training import TrainingConfig

# 假设命令行: python train.py --batch_size=128 --optimizer.lr=0.001
config = parse_config(TrainingConfig)
# 结果: TrainingConfig(batch_size=128, optimizer=OptimizerConfig(lr=0.001, ...))

# 从文件 + 命令行覆盖
config = parse_config(
    TrainingConfig,
    config_path="training_config.yaml",
    args=["--batch_size=256"]
)
# 结果: 使用文件中的默认值，但 batch_size 被覆盖为 256

CLI 参数格式

# 顶级参数
--offline_steps=100000

# 嵌套参数（使用点号）
--optimizer.lr=0.001
--optimizer.weight_decay=0.0001

# 列表参数
--episodes=[1,2,3,4,5]

# 布尔参数
--use_async_envs=true
--save_video=false

4.7 配置验证 (validation/checker.py)

函数列表

validate_config(config) Any bool 验证配置对象

使用示例

from lerobot_config.validation import validate_config, check_config_consistency
from lerobot_config.training import TrainingConfig
from lerobot_config.dataset import DatasetConfig

# 验证单个配置
train_cfg = TrainingConfig(batch_size=32)
is_valid = validate_config(train_cfg)

# 检查配置间一致性
dataset_cfg = DatasetConfig(repo_id="waleo/pusht")
issues = check_config_consistency({
    "training": train_cfg,
    "dataset": dataset_cfg
})
# 例如: 检查 batch_size 是否与 num_workers 兼容

8. 性能考虑

8.1 性能目标

  • parse_config(): < 50ms（不含文件 I/O）
  • validate_config(): < 10ms
  • load_plugin(): < 1s（取决于插件大小）

8.2 优化策略

  • 配置解析使用惰性求值
  • 避免重复验证
  • 缓存插件元数据
