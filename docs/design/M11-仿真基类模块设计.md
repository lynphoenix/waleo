## 1. 模块概述

**模块名称**: `waleo.sim`
**版本**: v2.0.0 (多后端通用架构)
**描述**: 提供**通用多后端**机器人仿真环境集成，通过统一的后端抽象层支持多种仿真引擎，无需修改上游代码。

**核心设计理念**:
- ⭐ **多后端支持**: ManiSkill3, MuJoCo, PyBullet, IsaacSim
- ⭐ **统一接口**: 所有后端使用相同的 `make_env()` API
- ⭐ **通用参数**: 后端特定参数通过 `**kwargs` 灵活传递
- ⭐ **无侵入式**: 不修改任何上游仿真库代码
- ⭐ **可扩展**: 添加新后端只需实现 `SimulationBackend` 接口

**支持的仿真后端**:
| 后端 | 特点 | 适用场景 |
|------|------|----------|
| **ManiSkill3** | GPU 加速、高保真机器人操作 | 复杂操作任务 |
| **MuJoCo** | 高速物理仿真、经典控制 | Ant, Hopper 等 |
| **PyBullet** | 开源免费、易于安装 | 快速原型开发 |
| **IsaacSim** | NVIDIA PhysX、高保真 | 与真实世界 1:1 |

## 2. 模块职责

### 2.1 核心职责
- **后端抽象**: `SimulationBackend` 基类定义统一接口
- **多后端支持**: ManiSkill3, MuJoCo, PyBullet, IsaacSim
- **统一工厂函数**: `make_env()` 一行代码创建任意后端环境
- **资源管理**: 通过 AssetResolver 管理 URDF、mesh、配置文件
- **机器人注册系统**: 从 YAML 加载机器人规格，自动发现并注册
- **环境包装器**: 使用 Gymnasium Wrapper 模式注入配置

### 2.2 非职责
- 不实现自己的物理引擎（依赖各仿真库）
- 不涉及训练循环逻辑（属于 M13 训练模块）
- 不涉及策略模型（属于 M04-M06）
- 不涉及真实机器人控制（属于 M09 机器人模块）
- 不修改任何上游库代码

## 4. API 设计

### 4.1 统一工厂函数 (`factory.py`)

**核心 API**：一行代码创建任意后端环境

```python
from waleo.sim import make_env

# ✨ ManiSkill3 (机器人操作)
env = make_env("PickCube-v1", obs_mode="state", control_mode="pd_joint_pos")

# ✨ MuJoCo (经典控制)
env = make_env("Ant-v4", backend="mujoco", frame_skip=5)

# ✨ PyBullet (开源机器人)
env = make_env("KukaBulletEnv-v0", backend="pybullet")

# ✨ IsaacSim (高保真仿真)
env = make_env("Isaac-Lift-Cube-Franka-v0", backend="isaacsim", num_envs=8192)

# ✨ 自定义机器人
env = make_env("PickCube-v1", robot_id="RJ2506")
```

**函数签名**：

```python
def make_env(
    task: str,                      # 任务名称
    robot: str = "panda",            # 内置机器人
    backend: str = "maniskill",      # 仿真后端
    num_envs: int = 1,               # 并行环境数
    robot_id: Optional[str] = None,  # 自定义机器人
    **kwargs                         # 后端特定参数
) -> Any:
    """创建仿真环境（统一入口）

    Args:
        task: 任务名称（各后端定义不同）
        robot: 内置机器人名称
        backend: 仿真后端 ("maniskill", "mujoco", "pybullet", "isaacsim")
        num_envs: 并行环境数量
        robot_id: 自定义机器人 ID
        **kwargs: 后端特定参数

    Returns:
        gym.Env: 配置好的环境实例
    """
```

### 4.2 后端抽象 (`backends/base.py`)

```python
class SimulationBackend(ABC):
    """仿真后端抽象基类"""

    import_name: str  # pip 包名

    @classmethod
    @abstractmethod
    def create(cls, task: str, **kwargs) -> Any:
        """创建环境"""

    @classmethod
    def is_available(cls) -> bool:
        """检查后端是否可用"""

    @classmethod
    def get_default_kwargs(cls) -> dict[str, Any]:
        """获取默认参数"""

    @classmethod
    def list_available_tasks(cls) -> list[str]:
        """列出可用任务"""
```

### 4.3 后端特定参数

| 后端 | 特定参数 | 示例 |
|------|----------|------|
| **ManiSkill** | `obs_mode`, `control_mode`, `robot_uids` | `obs_mode="state", control_mode="pd_joint_pos"` |
| **MuJoCo** | `frame_skip` | `frame_skip=5` |
| **PyBullet** | `physics` | `physics="gui"` |
| **IsaacSim** | `headless`, `device` | `headless=True, device="cuda:0"` |

## 5. 使用场景

### 5.1 跨后端训练

同一套训练代码，切换不同仿真器：

```python
from waleo.sim import make_env

# 根据可用性选择后端
backend = "maniskill" if ManiSkillBackend.is_available() else "mujoco"

env = make_env("PickCube-v1", backend=backend, num_envs=64)

# 训练循环（后端无关）
for episode in range(1000):
    obs, info = env.reset()
    while True:
        action = policy.predict(obs)
        obs, reward, terminated, truncated, info = env.step(action)
        if terminated or truncated:
            break
```

### 5.2 后端对比

```python
from waleo.sim import make_env

# 在不同后端上测试同一个策略
for backend in ["maniskill", "mujoco"]:
    env = make_env(task, backend=backend)
    rewards = evaluate_policy(env, policy)
    print(f"{backend}: {rewards.mean():.2f}")
```

## 6. 扩展新后端

**三步添加新后端**：

1. **创建后端类** (`backends/newbackend.py`)
```python
class NewBackend(SimulationBackend):
    import_name = "newbackend"

    @classmethod
    def create(cls, task: str, **kwargs):
        # 检查依赖、创建环境、返回
        ...
```

2. **注册到工厂** (`factory.py`)
```python
_BACKENDS["newbackend"] = NewBackend
```

3. **导出** (`backends/__init__.py`)
```python
from .newbackend import NewBackend
```
