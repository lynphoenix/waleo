## 使用示例对比

### 旧方式 (设计文档中的)
```python
# 不推荐
from waleo_utils import init_logging, write_video
logger = init_logging()
write_video("output.mp4", frames)
```

### 新方式 (实际实现)
```python
# 推荐 ✅
from waleo_utils import create_logger, save_video
logger = create_logger()
save_video("output.mp4", frames, fps=30)
```

### RNG管理对比

**旧方式（函数式）**:
```python
# 设计中的函数式API
state = get_rng_state()
save_rng_state("state.pkl")
load_rng_state("state.pkl")
set_rng_state(state)
```

**新方式（面向对象）**:
```python
# 现代化的类接口 ✅
manager = RNGManager(seed=42)
state = manager.get_state()
manager.save_state("state.pkl")
manager.load_state("state.pkl")
manager.set_state(state)
```
