## 实现细节

### 随机数管理兼容函数实现
```python
def get_rng_state():
    """获取所有 RNG 状态（兼容别名）"""
    manager = RNGManager()
    return manager.get_state()

def set_rng_state(state):
    """设置所有 RNG 状态（兼容别名）"""
    manager = RNGManager()
    manager.set_state(state)

def save_rng_state(path):
    """保存 RNG 状态到文件（兼容别名）"""
    manager = RNGManager()
    manager.save_state(path)

def load_rng_state(path):
    """从文件加载 RNG 状态（兼容别名）"""
    manager = RNGManager()
    manager.load_state(path)
```

这种实现方式：
- ✅ 提供了设计文档中要求的函数式API
- ✅ 内部使用了更现代的 `RNGManager` 类
- ✅ 保持了API的一致性和易用性
