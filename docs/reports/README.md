## 报告类型

### 改进报告
记录模块改进的决策过程和结果。

**包含内容**：
- 改进目标
- 方案对比
- 最终决策
- 实施结果
- 测试验证

### 验证报告
记录质量检查和验证的结果。

**包含内容**：
- 验证范围
- 发现的问题
- 修复方案
- 验证结果
- 建议措施

### 重构报告
记录重大重构的过程和影响（通常在 `migration/` 目录）。

## 报告编写规范

撰写新报告时，请遵循以下规范：

1. **标题**：清晰描述报告主题
2. **日期**：标注报告日期
3. **概要**：1-2 段总结
4. **详细内容**：分章节说明
5. **结果**：量化的结果数据
6. **建议**：后续改进建议
7. **格式**：使用 Markdown
8. **命名**：`模块名-报告类型-日期.md`
