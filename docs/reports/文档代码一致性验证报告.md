## 🔍 详细发现与修复

### P0 - 导入路径错误（已修复）

#### 1. examples/simple_example.py
**问题**：
- 第15行：`from waleo.config import EnvConfig`
- 第193行：`from waleo.config import EnvConfig`

**原因**：EnvConfig 已从 waleo.config 迁移到 waleo.sim

**修复**：
```python
# 修改前
from waleo.config import EnvConfig

# 修改后
from waleo.sim import EnvConfig
```

**影响**：如不修复会导致 ImportError

---

#### 2. tests/test_sim/test_basic.py
**问题**：
- 第16行：`from waleo.config import EnvConfig, CameraConfig`
- 第96行：`from waleo.config import EnvConfig`

**修复**：
```python
# 修改前
from waleo.config import EnvConfig, CameraConfig

# 修改后
from waleo.sim import EnvConfig, CameraConfig
```

**影响**：测试无法运行
